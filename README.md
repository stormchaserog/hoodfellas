# Hood Fellas ($HOOD)

**Hood Fellas** is a mafia-themed crypto game on Robinhood Chain. Players build families, claim turf, run jobs, fight wars and play casino tables — all powered by the $HOOD token.

## Tokenomics

- **3% tax** on trades funds the Season prize pool.
- Every **14 days** the top 3 families in the game split the pool **50 / 30 / 20**.
- Inside a winning family, the payout is split by each member's Season Points, so contributors earn more than passengers.

## The game

- **Families** — up to 25 members, led by a Don who founds a home city on the turf map.
- **Wars** — families fight for turf; War Power blends $HOOD held in-game with earned street power.
- **Season Points** — earned from holding $HOOD in-game, winning wars, in-game achievements and sharing achievements to X and Block Social.
- **Casino** — blackjack, poker rooms and tournaments, slots, roulette and a sportsbook, with $HOOD as the house currency.
